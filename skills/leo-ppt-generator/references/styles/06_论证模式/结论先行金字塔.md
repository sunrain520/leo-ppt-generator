# 论证模式：结论先行金字塔

结论先行论证。先给答案，再用结构化证据支撑——每条主张都挣得它的位置，数据被语境化而不编造对比。适合想看结果再看过程的听众：高管、董事会、投资人、决策者。

---

## 1. 论证骨架

**结论先行**：页面标题本身就是结论，不是标签。正文在标题下展开支撑论据。

**SCQA 开场，金字塔正文**：

| 阶段 | 角色 | 位置 |
|---|---|---|
| 情境 Situation | 建立共识上下文 | 开场页 |
| 冲突 Complication | 张力 / 问题 | 早期页 |
| 问题 Question | 待解决的隐含问题 | 转折 |
| 答案 Answer | 用结构化证据展开的建议；源支持时用 MECE | 正文页 |

**断言式标题**——写发现，不写主题：

| 弱（主题） | 强（断言） |
|---|---|
| 「市场概况」 | 「国内市场同比增长 23%，跑赢全球均值」 |
| 「挑战」 | 「三个结构性矛盾阻碍规模化部署」 |
| 「我们的方案」 | 「三阶段路径：聚焦、扩张、规模化」 |

**数据语境化**——数据配一个受支持的对比（当对比能改变决策时），否则直接说明其含义。绝不编造上期/基准/竞品/目标/排名来满足模式。

**结构化分解**——拆驱动/细分/选项时，分支要有意义地区分并覆盖决策所需。保留真实重叠或明确缺口，不硬造完美 MECE。

## 2. 页面结构倾向

- 标题（结论）→ 一句要点 → 下方支撑证据。
- 每页正文围绕一个决策相关问题，陈述明确结论。
- 分解页（驱动树 / MECE 拆解 / 2×2 矩阵）承担分析负载。
- 每张数据页标注来源。

> 页面结构是倾向，不是坐标模板。本模式决定「每页论证什么」，不决定像素位置。

## 3. 演讲备注语域

结论驱动：每页备注以要点开场，再用一组紧凑事实展开。沉稳、权威。数字配受支持对比时用口语化表达（「23%——接近行业 12% 的两倍」）。

## 4. 页面骨架示例

```
标题:    「留存，而非获客，现在驱动增长」  ← 是结论
要点:    一行——「CAC 同比涨 40%，但复购贡献了 60% 的收入增长」
正文:    支撑论据分层排列（驱动树 / 2×2）
```
