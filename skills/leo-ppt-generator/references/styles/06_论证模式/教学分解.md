# 论证模式：教学分解

教学式讲解。把概念拆成有序、可消化的部分，一步步建立理解。适合培训、教程、讲解、科普、知识分享。

---

## 1. 论证骨架

**先分解，再排序**：把主题拆成部分，按刻意顺序呈现（简单→复杂、前提→依赖、总览→细节）。

**聚焦学习单元**：每页围绕一个连贯的教学步骤；相关概念可共享一页，当它们的关系正是学习者需要理解的。

**平行呈现**：同级概念用平行结构——同形状、同深度——让听众能对比、映射。

**接地抽象**：用具体例子或类比澄清原理；例子与解释的顺序按学习者的前置需求。

**路标**：定向学习者——讲了什么、接下来讲什么。

标题陈述「这页教什么」（「注意力权重如何计算」）——清楚胜于聪明。

## 2. 页面结构倾向

- 编号步骤 / 有序流程；同级概念用平行卡片。
- 图解逐步累积；标注正在解释的部分。
- 具体例子锚定抽象点。

> 本模式决定「学习顺序与粒度」。

## 3. 演讲备注语域

耐心、解释性。先定义再用；先类比后原理。预判学习者的疑问并回答。节奏稳；路标过渡（「有了 X，我们现在可以问 Y」）。口语化数据。

## 4. 页面骨架示例

```
标题:  「第 2 步——对每个 token 按查询打分」
正文:  具体例子（3 个 token）→ 它说明的规则 → 一张图解
备注:  「还记得上一页的查询吗？这是它接下来做的……」
```
