# 论证模式：视觉展示

视觉主导冲击。让图像、尺度与节奏承载信息；最小化文案、最大化存在感。适合产品发布、品牌揭晓、活动开场、推广 deck。

---

## 1. 论证骨架

**图/数字主导，文字支撑**：通过主图、大数字、或短句建立主导视觉层级；支撑元素可共享页面但不抢焦点。

**情绪节奏**：建与放——一串大胆页由一页安静页打断。为感受而非密度定节奏。

**主想法放大陈述**：每页围绕一个清晰要点，以尺度表达；保留听众理解/信任所需的支撑上下文。

**揭晓结构**：先按住，再揭晓（产品、结果、口号）以达到最大效果。

标题短而唤起——一个短语，不是句子。

## 2. 页面结构倾向

- 全幅图 + 覆盖文字；一个焦点主数字或短语。
- 主视觉关系周围大量负空间。
- 大胆使用 deck 主题色营造氛围（封面 / 章节页）。

> 本模式决定「每页让什么成为主角」。

## 3. 演讲备注语域

有能量、唤起——设情绪、建期待。短促有力。让视觉干活，围绕它叙述感受。

## 4. 页面骨架示例

```
揭晓页：全幅产品图 + 一行——「认识新标准。」
证明页：单个大数字「10×」+ 一个短语，大片留白
备注:   「想象把它砍到几秒。这就是它做的事。」
```
