# 信息图类型：矩阵（matrix）

2×2 象限网格（偶尔 3×3），每格携带标签/颜色/图标。用于两条正交轴把图像划分为离散定性区。

> **在 PPT 块里的含义**：画布被垂直轴**严格均分为四象限**。与 `框架图`（中心 hub）不同，矩阵无中心——意义在四格；与 `对比图`（左右两半）不同，矩阵**横竖都分**。

## 1. 构图骨架

```
   ┌────────────────┬────────────────┐
   │   象限 1       │   象限 2       │
   │   (图标)       │   (图标)       │
   ├────────────────┼────────────────┤
   │   象限 3       │   象限 4       │
   │   (图标)       │   (图标)       │
   └────────────────┴────────────────┘
        ↑                ↑
   两条垂直轴在中心相交
```

| 维度 | 规则 |
|---|---|
| **布局** | 两垂直轴在画布中心相交，均分 4 象限 |
| **元素** | 每象限一个图标 + 可选轴端指示；每象限用 deck 调色板不同色相 |
| **负空间** | 象限内图标占 40-60% |
| **平衡** | 四象限视觉等重 |

## 2. 文本策略

- **无文本**：象限仅图标；轴标签与象限名由 SVG 叠加（模型渲染四位置轴标签常不一致，低风险路径）。
- **嵌入文本**：象限名嵌入画面，保持精简、回显 deck 正文字体。

## 3. Fewshot 片段

> 干净扁平 2×2 定性矩阵。两条细主色深蓝 `#1E3A5F` 线在画布中心相交。四象限各用不同淡色底（10-18% 透明度）。每象限一个主色图标（指南针/闪电/靶心/警示三角），占象限约 45%。四角小强调金点。无任何文字——SVG 外置标签。色值为渲染指导。
