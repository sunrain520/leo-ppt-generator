# 信息图类型：流程图（flowchart）

顺序块 + 方向箭头，展示过程/工作流/管线。用于「如何运作」、入职步骤、管线图、顺序方法论。

> **在 PPT 块里的含义**：图像内部是 3-6 个阶段的有向序列。与 `信息图`（平行分区）不同，流程图有**方向**；与 `框架图`（中心+卫星）不同，流程图有**顺序**。

## 1. 构图骨架

三个子结构：

**横向流**（最常见）
```
   ┌───┐ → ┌───┐ → ┌───┐ → ┌───┐
   │ 1 │   │ 2 │   │ 3 │   │ 4 │
   └───┘   └───┘   └───┘   └───┘
```

**纵向流**
```
   ┌───┐
   │ 1 │
   └─┬─┘
     ↓
   ┌───┐
   │ 2 │
   └───┘
```

**循环流**
```
   ┌───┐ → ┌───┐
   │ 1 │   │ 2 │
   └───┘   └─┬─┘
     ↑       ↓
   ┌───┐ ← ┌───┐
   │ 4 │   │ 3 │
   └───┘   └───┘
```

| 维度 | 规则 |
|---|---|
| **布局** | 3-6 个顺序块，方向箭头连接；有明确方向 |
| **元素** | 每块一个图标/编号 + 方向箭头；块视觉一致 |
| **负空间** | 块间留白足够，箭头清晰 |
| **方向** | 方向无歧义（左→右 = 先→后） |

## 2. 文本策略

- **无文本**：每块仅图标/编号；标签由 SVG 叠加。
- **嵌入文本**：每块可含短标签（步骤名），保持精简。

## 3. Fewshot 片段

> 干净扁平矢量流程图。四个顺序块从左到右，箭头连接。块为主色深蓝 `#1E3A5F` 描边，第二块强调金 `#D4AF37` 高亮。每块一个白色图标。无文字——SVG 外置步骤名。色值为渲染指导。
