# 信息图类型：时间线（timeline）

沿时间轴的线性进展——里程碑、演进、路线图、历史。用于公司历史、产品演进、项目路线图、时代叙事。

> **在 PPT 块里的含义**：图像内部有清晰轴（横或竖）+ 3-6 个里程碑标记。与 `流程图`（过程+箭头）不同，时间线关乎**时间位置**；与 `框架图`（关系）不同，时间线是**顺序且时序**。

## 1. 构图骨架

**横向时间线**（最常见）
```
   ──●─────●─────●─────●─────●──
     |     |     |     |     |
   2020  2021  2022  2023  2024
   icon  icon  icon  icon  icon
```

**纵向时间线**
```
   ●─── 里程碑 1
   │
   ●─── 里程碑 2
   │
   ●─── 里程碑 3
```

| 维度 | 规则 |
|---|---|
| **布局** | 清晰轴 + 3-6 里程碑标记（点/小形）沿轴分布 |
| **元素** | 轴线细而均匀；里程碑标记视觉一致；图标简单平行 |
| **负空间** | 轴上下（或左右）留白充足 |
| **时间方向** | 方向无歧义（左→右 = 早→晚） |

## 2. 文本策略

- **无文本**：每里程碑仅图标；日期/描述由 SVG 叠加。
- **嵌入文本**：可含短日期（「2020」「Q1」「v1.0」），只日期或短锚点，非描述。

## 3. Fewshot 片段

> 干净扁平时间线横幅。细主色深蓝 `#1E3A5F` 横轴在中高。五个圆形里程碑等距，第三（中心）用强调金 `#D4AF37` 环高亮（<5% 强调面积）。每标记上一个图标（种子/芽/苗/树/森林）讲成长序列。背景浅灰。无文字。色值为渲染指导。
