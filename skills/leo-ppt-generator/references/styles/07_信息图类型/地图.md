# 信息图类型：地图（map）

风格化地理轮廓（国家/地区/洲/世界）+ 标注标记——图钉、点、高亮区、连接线。用于办公地点、市场分布、区域数据、供应链路线、扩张路线图。

> **在 PPT 块里的含义**：示意地理可视化，非照片级地球。简化轮廓、刻意标记、极少制图细节。与 `信息图`（抽象数据区）不同，地图有**真实地理形状**锚定构图。

## 1. 构图骨架

```
   ┌────────────────────────────────────┐
   │        ▓▓▓▓▓                        │
   │     ▓▓▓     ▓▓▓     ●               │
   │   ▓▓          ▓▓▓                   │
   │   ▓ 风格化     ▓▓     ●            │
   │   ▓▓ 大陆      ▓▓                 │
   │    ▓▓▓          ▓▓                  │
   │      ▓▓▓     ●▓▓                    │
   │         ▓▓▓▓▓                       │
   │   ●  = 位置标记                     │
   └────────────────────────────────────┘
```

| 维度 | 规则 |
|---|---|
| **布局** | 一个或多个简化大陆轮廓 + 3-12 标记点 + 可选连接弧 |
| **元素** | 大陆（平涂或轮廓）+ 标记 + 可选区域高亮（1-2 区加深色） |
| **负空间** | 海洋/留白 ≥25% 画布；标记不挤边缘 |
| **平衡** | 地理近似但可辨识——一眼认出区域 |

## 2. 文本策略

- **无文本**：城市/国家/地区名由 SVG 叠加；图只显示标记。
- **嵌入文本**：复古制图/图册式海报可嵌入地名，用前核拼写与位置。
