# 信息图类型：对比图（comparison）

分割构图展示两个对立面——左 vs 右、前 vs 后、A vs B、传统 vs 新。用于优缺点、心态转变、方案评估、转型故事。

> **在 PPT 块里的含义**：图像内部有两个对称或近似对称的半区，带清晰分隔。每半代表一个选项/状态。与所有其他类型不同，对比图的签名是**显式二元性**。

## 1. 构图骨架

**横向分割**（最常见）
```
   ┌────────────┬────────────┐
   │   左       │   右       │
   │  (before,  │  (after,   │
   │   A)       │   B)       │
   └────────────┴────────────┘
```

**纵向分割**
```
   ┌──────────────┐
   │    上(before)│
   ├──────────────┤
   │    下(after) │
   └──────────────┘
```

| 维度 | 规则 |
|---|---|
| **布局** | 两近似等半 + 清晰分隔（竖或横） |
| **元素** | 每侧一个锚点元素（图形/图标簇/图表/场景）；结构对称、内容各异 |
| **负空间** | 外缘 12-15% 内边距 |
| **分隔** | 干净——细线/竖规则/几何形/留白，显有意 |

## 2. 文本策略

- **无文本**：每侧仅视觉锚点（图形/图标/场景）；「前/后」「A/B」由 SVG 叠加。
- **嵌入文本**：侧标签精简嵌入。

## 3. Fewshot 片段

> 干净扁平对比图。竖中线把画布均分左右。左侧淡灰 `#F8F9FA` 底 + 一个「旧」图标，右侧主色深蓝 `#1E3A5F` 底 + 一个「新」图标。分隔线为细主色。无文字——SVG 外置 A/B。色值为渲染指导。
