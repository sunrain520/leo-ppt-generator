# 信息图类型：框架图（framework）

中心概念 + 相关子概念，或多组件系统的关系结构。用于让关系系统/架构**一眼可读**。

> **在 PPT 块里的含义**：图像本身是小型关系图——中心 hub + 辐射卫星、标注矩阵、或分层堆栈。与 `信息图`（平行）、`流程图`（顺序）都不同，框架图是**关系结构**。

## 1. 构图骨架

三个有效子结构，每图只选一个，不混用：

**子结构 1 —— Hub 与辐条**（最常见）
```
        ◯
         \
   ◯ ─── ◆ ─── ◯
         /
        ◯
```
- 中心一个几何锚点（圆/圆角方/菱形/六边形）+ 3-6 卫星。
- 卫星视觉一致（同形族、同尺寸、同色）；连接线细、等重。
- 负空间充足；对称或刻意不对称，绝不偶然失衡。

**子结构 2 —— 矩阵**（2×2 或 3×3）
```
   ┌──────┬──────┐
   │      │      │
   ├──────┼──────┤
   │      │      │
   └──────┴──────┘
```
- 等大网格，每格一个概念；内容占格内 70%。

**子结构 3 —— 分层堆栈**
```
   ╔══════════╗
   ║  layer 3 ║
   ╠══════════╣
   ║  layer 2 ║
   ╠══════════╣
   ║  layer 1 ║
   ╚══════════╝
```

## 2. 文本策略

- **无文本**：节点仅图标；标签由 SVG 叠加。
- **嵌入文本**：节点名精简嵌入画面。
