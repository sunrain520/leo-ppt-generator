# 信息图类型：场景（scene）

带叙事的氛围环境——一个时刻、一个地点、一个情境，渲染成小故事。用于案例、品牌叙事、生活方式、个人叙事页。

> **在 PPT 块里的含义**：图像内部是「某地的一个时刻」——环境、人物（如有）、氛围、情绪。与 `hero`（单一主主体）不同，场景有**上下文与叙事**；与 `背景`（无主体）不同，场景有**居者**。

## 1. 构图骨架

```
   ┌────────────────────────────────────┐
   │  天空 / 氛围（前景或上区）          │
   │                                    │
   │   人物/主体在环境中                │
   │           ↑ 前景                  │
   │  ────────────────────────────      │
   │   中景（上下文、物体）             │
   │  ────────────────────────────      │
   │   背景（氛围深度）                 │
   └────────────────────────────────────┘
```

| 维度 | 规则 |
|---|---|
| **布局** | 三层：前景（主体+近景）、中景（支撑环境）、背景（氛围深度）；读者像读小故事 |
| **元素** | 一个或多个人物在环境内；环境元素（太阳/灯/树/桌）支撑叙事 |
| **负空间** | 大气透视制造呼吸——背景比前景淡 |
| **氛围** | 光向、色温、情绪刻意（黄金时刻/暮光/晨雾等） |

## 2. 文本策略

- **无文本**：场景是视觉叙事，多数读感更好的是文字走 SVG 叠加。
- **嵌入文本**（装饰氛围字或剧情字）：装饰氛围大字（如「WANDER」）作视觉情绪；剧情字（场景里的招牌/书名）常渲染失败，仅叙事必需时用。

## 3. Fewshot 片段

> 暖色调氛围场景。暖光下一个人物在书桌前，前景是主体与书桌，中景是房间元素，背景是晨雾窗外。光向与色温刻意（暖金时刻）。无文字。色值为渲染指导。
