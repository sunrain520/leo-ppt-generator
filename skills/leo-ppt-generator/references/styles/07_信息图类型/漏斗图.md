# 信息图类型：漏斗图（funnel）

上宽下窄的水平带堆栈，代表连续转化阶段。每带比上一层窄，暗示随过程推进的流失/过滤。用于营销漏斗、销售管线、招聘漏斗、客户旅程转化。

> **在 PPT 块里的含义**：向下收敛的堆栈——视觉重量随下移缩小，体现「上方很多人进入，底部少数到达」。与 `金字塔`（通常向上收窄表层级/价值）不同，漏斗**始终宽→窄向下**，且关乎**过滤**而非层级。

## 1. 构图骨架

```
   ┌──────────────────────────────────┐ ← 带 1（最宽）
   │             认知                 │
   ├────────────────────────────────  ┤
    ┌────────────────────────────┐    ← 带 2
    │          兴趣              │
    ├──────────────────────────  ┤
      ┌──────────────────────┐         ← 带 3
      │       考虑           │
      ├────────────────────  ┤
        ┌──────────────┐               ← 带 4
        │    转化      │
        └──────────────┘
```

| 维度 | 规则 |
|---|---|
| **布局** | 3-6 水平带垂直堆叠；每带宽度较上层缩小 15-25% |
| **元素** | 每带左一个图标 + 带本身为主色块；可选细分隔线 |
| **负空间** | 侧边距随带变窄而增大 |
| **平衡** | 垂直中轴是漏斗脊柱，所有带居中 |

## 2. 文本策略

- **无文本**：每带仅图标；阶段名由 SVG 叠加。
- **嵌入文本**：带名精简嵌入画面。

## 3. Fewshot 片段

> 干净扁平营销转化漏斗。四水平带垂直堆叠，各带较上层窄约 20%。带 1 主色深蓝 `#1E3A5F`，带 3 强调金 `#D4AF37`。每带左一白色图标（喇叭/心/购物车/星）。细奶油 `#F8F9FA` 分隔线。无文字。色值为渲染指导。
