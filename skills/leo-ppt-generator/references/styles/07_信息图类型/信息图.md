# 信息图类型：信息图（infographic）

2-5 个**平行有序分区**，每区一个图标 + 极简标签。用于数据总结、KPI 罗列、步骤清单、特性亮点、价值主张的可视化。

> **在 PPT 块里的含义**：图像内部是一个 2-5 分区的信息面板。与 `框架图`（中心+辐射）、`流程图`（顺序+箭头）不同，信息图是**平行分区**，无严格顺序、无方向流。

## 1. 构图骨架

两个子结构：

**子结构 1 —— 网格**（最常见）

```
   ┌──────┬──────┐        ┌──────┬──────┬──────┐
   │      │      │        │      │      │      │
   ├──────┼──────┤  或    └──────┴──────┴──────┘
   │      │      │
   └──────┴──────┘
   2×2（4 区）             3×1（3 区）
```

**子结构 2 —— 辐射**（4-5 区围绕小中心锚点）

```
       ◯
        \
   ◯─── · ───◯
        /
       ◯
```

| 维度 | 规则 |
|---|---|
| **布局** | 2-5 个等权重分区，网格或辐射排列；每区视觉独立（各色/各图标）但结构平等 |
| **元素** | 每区一个图标 +（可选）一个短关键词；连接线非必需 |
| **负空间** | 区间 10-15% 沟槽；区内 60-70% 给内容、余为内边距 |
| **平衡** | 各区分区视觉平等，无一区主导 |

## 2. 文本策略

- **无文本**：每区仅图标；标签由 SVG 叠加。
- **嵌入文本**：每区图标 + 一个短关键词（≤2 词）；关键词是画面的一部分，无长句无数字。

## 3. Fewshot 片段

> 干净扁平矢量信息图。2×2 等大圆角矩形分区，沟槽约画布宽 12%。四区各用 deck 调色板不同色相：左上主色深蓝 `#1E3A5F`，右下强调金 `#D4AF37`（约 7% 强调面积）。2px 描边、8% 软投影。每区一个白色图标（柱状图/灯泡/靶心/上箭头）。背景浅灰 `#F8F9FA`。无任何文字/字母/数字——标签由 SVG 外置。色值为渲染指导。
