# 信息图类型：循环图（cycle）

闭环流程——3-6 步排成圆（或圆角环），方向箭头连接并回到起点。用于迭代过程、持续改进、生命周期。

> **在 PPT 块里的含义**：闭合循环流——每步指向下一步，最后一步指回第一步。与 `流程图`（线性单向）不同，循环图无终点；与 `框架图`（中心 hub + 被动卫星）不同，循环图沿圆周有方向运动。

## 1. 构图骨架

```
             ┌─────────┐
       ┌────▶│ Step 1  │────┐
       │     └─────────┘     │
       │                     ▼
   ┌───┴───┐             ┌─────────┐
   │ Step 4│             │ Step 2  │
   └───────┘             └────┬────┘
       ▲                      │
       │     ┌─────────┐      │
       └─────│ Step 3  │◀─────┘
             └─────────┘
```

| 维度 | 规则 |
|---|---|
| **布局** | 3-6 步节点沿圆/圆角方排列，箭头连接并闭合 |
| **元素** | 每步一个图标 + 方向箭头；可选中心锚点 |
| **负空间** | 圆心安静——空或只放小锚点 |
| **平衡** | 步节点沿圆周均匀，箭头等重 |

## 2. 文本策略

- **无文本**：每步仅图标；步名由 SVG 叠加。
- **嵌入文本**：步名精简嵌入画面。

## 3. Fewshot 片段

> 干净扁平矢量循环图。四个圆角方块沿圆周均匀分布，方向箭头闭合。每块一个白色图标，一块强调金 `#D4AF37`。圆心留空。无文字。色值为渲染指导。
