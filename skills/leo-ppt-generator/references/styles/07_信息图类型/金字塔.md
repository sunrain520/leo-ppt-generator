# 信息图类型：金字塔（pyramid）

分层的三角形堆栈——下宽上窄——每层携带标签/颜色/概念。用于能力堆栈、价值层级、软件架构层。

> **在 PPT 块里的含义**：向上收敛的层叠结构，体现「基础支撑价值」——宽稳底、窄顶。与 `漏斗`（向下收窄、关乎过滤）不同，金字塔**向上收窄**，关乎**价值/层级堆叠**；与 `框架图`（中心 hub）不同，金字塔**严格垂直分层**。

## 1. 构图骨架

```
              ┌──────┐                ← 顶端（最小）
              │ T 5  │
            ┌─┴──────┴─┐
            │   T 4    │
          ┌─┴──────────┴─┐
          │     T 3      │
        ┌─┴──────────────┴─┐
        │       T 2        │
      ┌─┴──────────────────┴─┐
      │         T 1          │       ← 基础（最宽）
      └──────────────────────┘
```

| 维度 | 规则 |
|---|---|
| **布局** | 3-6 水平层垂直堆叠，每层较下层窄；可三角轮廓或阶梯直角 |
| **元素** | 每层一个图标 + 层本身为主色块；色相通常底重顶亮（或反之） |
| **负空间** | 侧边距随层变窄而增大 |
| **平衡** | 垂直中轴是脊柱，所有层居中 |

## 2. 文本策略

- **无文本**：每层仅图标；层名由 SVG 叠加。
- **嵌入文本**：层名精简嵌入画面。

## 3. Fewshot 片段

> 干净扁平层级金字塔。五水平阶梯层垂直堆叠，各层较下层窄约 18%。从底到顶：深主色 `#1E3A5F` → 渐浅 → 顶端强调金 `#D4AF37`。每层一个白色图标（砖/盾/齿轮/上箭头/星）。细奶油分隔线。无文字。色值为渲染指导。
