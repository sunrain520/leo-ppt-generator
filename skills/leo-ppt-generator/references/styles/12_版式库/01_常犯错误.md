# 版式常犯错误（P0 检查项）

> 来自 guizang-ppt-skill Swiss 版式。每一项都是「版式层」的硬约束，生成后逐条自查。

## 版式 P0 错误

1. ❌ 给卡片加 `border-radius` → ✅ 必须直角
2. ❌ 在 `.card-accent` 上又加描边 → ✅ 卡片填充类型互斥（ink/accent/fill/outlined 四选一）
3. ❌ 自己画 SVG 图标 → ✅ 用 `lucide` 线上库，棱角风格
4. ❌ 时间线 dot 用 grid `justify-self` 对齐虚线 → ✅ axis 列固定 12px + dot 绝对定位
5. ❌ 大字号不限高（`13vw`）→ ✅ 永远 `min(Xvw, Yvh)` 双约束
6. ❌ ESC 索引页缩略图看不到带动效内容 → ✅ 给 cloned slide 加可见性 override CSS
7. ❌ 所有页用同一个 fade-up recipe → ✅ 每页一个语义化 recipe，与图形耦合
8. ❌ 标题 + 卡片间距 < 5vh → ✅ 章节级标题至少 9vh
9. ❌ 9px 圆形装饰点 → ✅ 8×8 直角小方块 / mono `t-meta` 文字
10. ❌ 装饰元素超出页面边距 → ✅ 严格在 grid 内，不贴边

## Swiss 对齐法则（每页必查，违反 = 整页报废）

1. **不二次叠加水平 padding** — `.canvas-card` 已自带 padding，主体层再写 padding 会变成双倍内缩、左右对不齐。
2. **kicker 必须在大标题上方**（上下结构，不是左右挤）。
3. **双约束限高 `min(Xvw, Yvh)` 中 Y ≥ X × 1.6** — Y 太严会被高度截断，字号整体缩小。
4. **canvas-card 子元素间用 grid `gap`**，不要靠 margin/padding 堆间距（会和 chrome-min 的 margin-bottom 重叠撕裂）。
5. **底部分页安全区** — 主内容最低处不要触及 nav（约 93vh 后），至少留 3vh 呼吸空间。

## Swiss 排印硬规则

- **越大越细，越小越粗**：≥8vw → weight 200；1-1.7vw/16-20px → 400-500；13-15px → 500-600。
- 同一页内，字号越小的元素字重必须 ≥ 字号越大的元素。
- 16px 左右小字拒绝 weight 300（太细不可读），最低 400。
- 封面/IKB 反白大标题内的强调字用 `italic + weight 300`，不要用 accent 色（蓝压蓝看不见）。
- 中文标题优先改短，其次降字号；不要让标题挤占下方图文区。
- 投屏最小字号：正文 18px / 卡片描述·caption·图注 16px / meta·kicker·图表标签 14px。

## Swiss 图片硬规则

- 图片是网格中的「证据块」，不是装饰背景；必须有明确功能（案例/实拍/UI/系统图/信息图）。
- 图片容器直角、无阴影、无圆角；默认不加外框，让 caption 或网格承担层级。
- 白底信息图/流程图/UI 图：容器背景须 `--paper`，不要灰底包白图，不要加描边。
- 纪实照片 `cover` 只裁底部；原始截图/文字密集图用 `.fit-contain`。
- S22 照片主体位于中央安全区，`object-position:center 35%` 或 `center center`，不要 `top center` 截人脸。
- 生成图只保留核心图像本身，不要把页眉/页脚/标题/页码/角标/边框画进图里。

## 版式多样性硬规则

- 7-8 页 deck 至少用 6 个不同版式。
- 不允许连续 3 页同一种主体结构。
- 测试模板必须覆盖：封面、收尾、至少 1 个对比/时间线、至少 1 个结构图、至少 1 个图片版式。
- 每页写代码前先列 `页码 → 版式 → 为什么选它 → 图片槽位`。
