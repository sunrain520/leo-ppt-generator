# 图文叠放规则（Image Overlay & Subject Safety）

来源：`ppt-github/guizang-social-card-skill/references/image-overlay.md`。约束**文字压在图片上**的任意页面（整幅铺底、大图照片井、生成图加字）。一条合成可通过 HTML lint 却仍不可读，两条规则须都通过才能交付。

## 规则 1 — 先选图，遮罩只在选图失败时用

编辑杂志的默认答案是**不加遮罩**。真杂志封面（Kinfolk / Cereal / Apartamento / Monocle）几乎从不往主图铺统一黑渐变，靠**选图 + 构图**让字落在安静区。

**Step 1 选图（主杠杆）** — 两张测试都要过：
- **安静区测试**：至少一个 ≥30% 画布的带（全宽×≥30% 高，或全高×≥30% 宽）是低细节/低对比/均匀的（失焦背景、深阴影、雾、静水、纯天、模糊草）。
- **光线测试**：图带**氛围/克制光**——阴天、晨雾、黄金时刻、林下、胶片柔光、黄昏剪影。拒绝高饱和正午、机顶闪光、游客自拍、通用棚拍欢快感。

任一不过 → 图不适配 M16，回退 M01（分栏封面把图放进框）或重新找图。**不要「用遮罩修」**。

**Step 2 先不加遮罩构图** — 标题放进合格安静区，跑 Step 4 缩略图对比，干净就发。多数好图在这步就能过。无遮罩封面是手艺，重遮罩封面是「没找到好图」。

**Step 3 局部、取图像色的柔 tint（仅回退）** — 只有 Step 2 对比失败才用，三规则：
1. **局部不整幅**：只 tint 标题区，`radial-gradient` 以标题块为中心，或单侧线性渐隐到全透明。绝不 `inset:0` 整幅。
2. **取图像色，不用黑**：森林→深苔 `#1a2818`；黄昏→茶玫 `#4a2638`；雪→冷灰蓝 `#2a3438`。纯黑 `#000` 读作「批注层」而非「氛围深度」。
3. **柔不实**：标题区峰值 alpha 0.15–0.30，向外降到 0。若需 >0.40 才可读，图没过 Step 1。

```css
.hero-bleed::after {
  background: radial-gradient(60% 45% at 25% 80%,
    rgba(26,40,24,.28) 0%, rgba(26,40,24,0) 100%);
}
```

**Step 4 缩略图对比（永远做）** — 导出 PNG，缩到 360px 宽看。标题笔画须不放大也清晰。标题「跟图打架」→ 换图或挪标题到别的安静区，**不是加强遮罩**；图在统一暗下发灰死 → 遮罩太重或盖错区，回 Step 1。

**禁用**：整幅纵向 falloff（`rgba(0,0,0,.55)→.10→.10→.80`，那是游戏 key-art）；纯黑遮罩；文字后平黑/白矩形；`mix-blend-mode: difference`；`img{opacity:.6}`；未试 Step 1 就先 Step 3。

## 规则 2 — 文字避开主体/人脸区

图有主体（脸/手/产品/峰），文字叠主体读作涂鸦。

**主体区发现（先多模态看图）** — 记录三点：主体脸/焦点在哪（如「脸在右上约 70% x 30% y」）、主体轮廓边界、最大低细节开放区。写成 HTML 注释（subject map），这是版式的输入，可复核。

**安全区放置优先级**：
1. **上 + 下**（kicker 在上、标题在下）——90% 全幅封面应如此。
2. **单侧**——主体占一竖列时，文字填对侧。
3. **对角**——仅主体在一角且对角真空，罕见。

**绝不把大标题压在脸上**。90px 中文标题切过人眼，即使加遮罩也毁。

**编辑式构图纪律（四规则）**：
- **非对称**：标题偏一侧/一角比死居中更自信。
- **充足负空间**：标题 ≤40% 画布。
- **标题只落一个安静区**（拆上+下可以，拆三处或绕主体太挤）。
- **标题不压主体轮廓**；若唯一安全位要跨主体边缘，换模式（加框/双联/离图标题），不要放大遮罩。

**裁剪守卫**（`object-position` 随主体位置）：
| 主体在原始图 | 3:4 裁剪建议 |
|---|---|
| 脸/焦点在上三分之一 | `center 25%` |
| 中三分之一 | `center center`（默认，字走上+下） |
| 下三分之一 | `center 70%` |
| 宽景无单一主体 | `center 35%`（保留地平线） |
| 竖构图全身 | `center top` |

**图容不下文字时**：移进小框（`.frame-img.r-3x4/.r-1x1`）、双联（一紧主体 + 一负空间，字压负空间那张）、或文字完全离图（标题在上、图在下）。图要独占画布 ≠ 文字该跟它打架。

## 交付前清单

- [ ] 图过安静区（≥30% 低细节带）且过光线测试。
- [ ] 先试无遮罩；tint 仅 Step 4 失败才加。
- [ ] 若加 tint：局部、取图像色、峰值 α≤0.30。
- [ ] 无整幅纵向 falloff。
- [ ] subject map 已写成注释。
- [ ] 无 ≥72px 大标题压脸/手/关键产品特征/主体轮廓。
- [ ] 标题 ≤40% 画布，非对称优先。
- [ ] `object-position` 按表选，非默认。
- [ ] 缩略图测试过。
- [ ] 无文字后平黑/白板。

## 16:9 适配

16:9 横向比 3:4 更宽，安静区常是「左右侧栏」（对应用规则 2 的「单侧」），标题偏左/偏右更自然。安静区/光线测试、取图像色 tint、主体避让、`object-position` 表全部直接适用。
