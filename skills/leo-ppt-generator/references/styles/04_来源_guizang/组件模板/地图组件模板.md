# 地图组件模板（.map-block）

来源：`ppt-github/guizang-social-card-skill/references/map-component.md`。内容含**空间关系**时用（路线、门店、步行游、街区概览、跨区对比、搬迁前后）。单点坐标（「我在北京」）不需要地图。

两种种子都带 `.map-block` + `.map-pin` + `.map-legend`；同一标记两种模式通用，仅风格锁定色调不同。

## 三种渲染模式（动手前定，不可叠加）

| 模式 | 何时 | 依赖 |
|---|---|---|
| **T · Mapbox Static**（真实路线默认） | 旅行/徒步/街区导览，需真实地形街道 | `MAPBOX_ACCESS_TOKEN` |
| **O · OSM 瓦片合成**（无 token 回退） | 同样需要真实地图，无 Mapbox | `staticmaps` npm 服务端 |
| **S · 示意 SVG**（概念/示意） | 概念关系图、虚构路线、纯编辑「地点如此相连」 | 无 |

风格 URL 白名单（保持单色）：`mapbox/light-v11`、`mapbox/dark-v11`、`mapbox/streets-v12`（仅配 `tone-paper`，绝不裸用）。**禁用** `outdoors-v12` / `satellite-v9`（太彩，撞两风格）。

**色调**：Editorial 用 `tone-paper`（multiply 混合、饱和度 36%）；Swiss 用 `tone-paper` 饱和度 0（纯灰）。绝不展示 Mapbox 原色彩风格。

## Mode S 示意 SVG（概念图）

`viewBox="0 0 100 100"`，风格化不 GPS 精确，**不**手描 OpenStreetMap。层序（后→前）：`.map-water`（河/湖/园）→ `.map-coast`（边界）→ `.map-grid`（可选网格）→ `.map-road`（交通线）。pin 在 SVG 外作 HTML 兄弟，自动获得 `.frame-shot` 处理。

```html
<div class="map-block r-16x10">
  <svg viewBox="0 0 100 100" preserveAspectRatio="none">
    <path class="map-coast" d="M 6 18 Q 32 22 58 16 T 96 28"/>
    <path class="map-road" d="M 8 78 Q 42 62 78 70 T 96 56"/>
    <path class="map-road" d="M 24 14 L 38 62 L 52 86"/>
    <path class="map-water" d="M 62 8 L 92 12 L 96 36 L 70 30 Z"/>
  </svg>
  <div class="map-pin" style="left:32%; top:48%;">
    <div class="dot"></div><div class="line"></div>
    <div class="card"><div class="name">大昭寺</div><span class="meta">DAY 1</span></div>
  </div>
  <div class="map-pin accent" style="left:62%; top:38%;">…</div>
  <div class="map-legend">LHASA · 拉萨城关 · 1:8K</div>
</div>
```

## 硬规则

- **无 pin 标签在 SVG/瓦片上**：名称活在 `.map-pin .card`，绝不 `SVG <text>` 或烤进地图图。保证字体一致、避免缩放问题。
- **每板 ≤6 pin**：再多卡片撞。次要点用关系/索引卡列。
- **至多 1 个强调 pin**。
- **pin 不叠卡片**：长轴 80px 内两卡就交替 `.left`。
- **无活 JS 地图**（静态 PNG；MapLibre 白费重量）。

## Pin 放置手册

`.map-pin` 用 `left:X%; top:Y%` 锚中心；卡片默认向右长，加 `.left` 翻转。经验：pin 在画布左 60% → 卡片开右（默认）；右 60% → 开左；两 pin 近 → 交替开边。

## 配方路由（地图并入既有配方，不单开）

| 配方 | 地图如何嵌 |
|---|---|
| M01 分栏 | 上半 `.map-block r-16x9`，下半说明文字 |
| M11 旁注 | 主栏 `.map-block r-3x4`，旁列关系卡 |
| M14 流水线 | 某一步含小图（r-16x10）示该步位置 |
| S02 双信号 | 一格放地图，另一格放数据表 |
| S08 图像英雄 | 用 `.map-block r-16x10` 替换 hero 照片 |

**不造「纯地图页」**——地图总配文字说明**为什么**这段空间关系重要。

## 色调 token

| Token | Editorial | Swiss |
|---|---|---|
| (none) | 仅 SVG 示意 | 仅 SVG 示意 |
| `tone-paper` | 暖纸 multiply，旅行默认 | 硬灰，一切默认 |
| `tone-ink` | 亮度 62%、饱和 18%，暗页 | 亮度 58%、饱和 0，暗海报 |

tone 只影响 `> img`，不影响 SVG 示意。

## 常见错误

贴 Google Maps 截图（色调错、带 UI chrome）→ 用 Mapbox Static / OSM / 示意；把真实地图描进 SVG（示意要**抽象**，观者能认出城市=描过头）；pin 卡太小（`.card .name` 15-16px 下限，超长裁名不缩字号）；每 pin 都强调。

## 16:9 适配

16:9 是地图组件的最佳画布（`r-16x10`/`r-16x9` 满幅，路线横向自然）。「一页一地图 + 说明」的 M01/S08 嵌入在横向更顺；`tone-paper`/`tone-ink` 的 Editorial/Swiss 去饱和直接照用。示意 SVG 在宽画布上横轴更有表现空间。
