# 竖图填充规则（Portrait Fill）

来源：`ppt-github/guizang-social-card-skill/references/portrait-fill.md`。3:4 竖向空间远多于横向 slide；16:9 能用的版式在 3:4 常变薄条。此文件是**竖向画布填满**的规则，核心「不欠填」原则同样反向适用 16:9。

## 竖向分区

把 1080×1440 图当五区：

| 区 | 典型高 | 角色 |
|---|---|---|
| Header/meta | 56-90px | 议题标签、分类、页码 |
| Title/lead | 240-420px | 钩子与主张 |
| Evidence/body | 520-760px | 图、台账、图解、对比 |
| Bottom strip | 90-180px | 说明、清单、总结 |
| Footer | 52-86px | 议题/页码元信息 |

不必每页五区齐全，但每页要有**有意的纵向构图**。

## 欠填气味（需改）

- 表格/台账占画布高 <45%。
- 下方 25% 空且不是氛围 hero 页。
- 四行列表排成短行、下方大片空白。
- 截图是证据却很小。
- 正文居中、无上下节奏。

## 薄表格修复

1. 行高提到 118-170px。
2. 左加边注列（大数字/关键词/分类标签）。
3. 表格旁加金句列。
4. 顶/底加议题条（2-3 条后果）。
5. 转成 M08 高台账。
6. 只有 2-3 点 → 用 M04 金句或 M09 氛围论点，别用表格。

## 稀疏文字修复

- 用 M09 氛围论点 + 可见 WebGL/ink 背景。
- 让那句话当 hero，不是小段落。
- 加一条小出处/上下文行。
- 需要节奏就上深色/ink 页。

## 截图页修复

- 给截图 45%-65% 页高。
- 上方只放一句关键句。
- 用底部说明带，不用侧边段落。
- 谨慎裁剪，保留可读 UI 标签。

## 页面节奏

7 页 set 至少 5 种形态：封面/特写 · 文章分栏 · 高台账 · 证据截图 · 金句/氛围论点 · 清单/对比 · 结语。`标题 + 导语 + 3 行` 在一个 set 里重复不超过两次。

## 最小占用率

活跃构图约占页高 **78%**：大字、图/截图、台账行、hero 页背景氛围、说明带、边注列都算。**留白只在被设计时才好，空余不是留白**。

## 16:9 适配

16:9 是横向画布，五区改横向：左标题带 / 中证据区 / 右结论带。核心不变的是「最小占用率 78%」与「欠填气味」——横向版把「下方 25% 空」换成「右侧 25% 空」，「薄表格」换成「窄表格」即触发同样的修复（加边注列、提行高、转高台账/金句）。页面节奏的「5 种形态、同一版式不重复两次」直接适用。
